# PowerPoint Masked Shape Overlay

![Screenshot of the prompt in use](./assets/demo.png)

## Summary

This prompt helps create a bold editorial poster slide in PowerPoint where an object or shape (this sample uses a lily flower) is cut out of a flat white panel like a stencil, revealing the background image through the silhouette.

## Prompt

```text
Create a bold editorial composition using **lily flower shape** as a large **cutout silhouette**.

Place a clean, solid-color geometric panel over the background, using white color. Cut the **lily flower shape** out of this foreground panel like a stencil or window, so the underlying background remains visible through the silhouette.

Make the cutout large, recognizable, and visually dominant. Allow parts of the silhouette to extend beyond or intersect the edges of the panel for a sophisticated editorial effect.

Keep the silhouette clean and simplified, with crisp edges and enough recognizable detail to clearly identify the subject. The cutout itself must contain the underlying background, not a separately illustrated or recolored version of the subject.

Use strong figure-ground contrast, generous negative space, asymmetrical composition, and a premium contemporary poster aesthetic. Avoid borders, outlines, drop shadows, bevels, or 3D effects.
```

## Description

This prompt is designed for Copilot in PowerPoint when a slide has a background image. Replace "lily flower" with any recognizable subject (for example a leaf, animal, or landmark) and change the panel color if desired. The silhouette acts as a transparent window in the panel, so the background shows through it.

## Use cases

- Title slides and section openers with a bold editorial look.
- Event, campaign, or product posters.
- Themed visuals where the shape reinforces the message.

## Instructions

1. Open PowerPoint.
2. Add a background image to a slide.
3. Open Copilot in PowerPoint.
4. Paste the prompt from the Prompt section, replacing `lily flower` and the panel color as needed.
5. Review the generated slide, then add or adjust text in the white panel.

## Prerequisites

- Copilot in PowerPoint.

## Help

This sample is provided for community use and learning. If the shape is drawn as a separate illustration instead of a window, re-run the prompt and emphasize that the background must show through the silhouette.
